# Reviews

- `daily/` - end-of-day review of the day's buys and sells (weekdays, ~22:13 Oslo time)
- `weekly/` - weekly review (Fridays, ~19:38 Oslo time)

Written by Claude from the portfolio state (branch `state`). Each new review is e-mailed
by the `email-review` workflow when the SMTP secrets are set. Suggestions are never applied automatically.
